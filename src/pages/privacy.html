隱私權政策

八字紫微排盤（網頁版，以及 iPhone、iPad App「排盤」）。生效日期：2026 年 11 月 24 日

一句話

我們不收集任何資料。你輸入的生辰只在你自己的裝置上計算，不會傳到網路上，開發者也看不到。

你輸入的資料存在哪裡

  • 排盤（四柱、大運、紫微十二宮、讀盤紀錄、星曜解讀）全部在你的裝置上計算，不需要註冊或登入。
  • 按「存」保存的生辰，只存在這台裝置上：網頁版存在瀏覽器裡；App 存在 App 裡，並在 App 自己的設定檔另外留一份備份，用來在系統清掉網頁資料時補回。
  • 這些資料不上傳、不同步到別的裝置。刪掉已存的盤、刪除 App（或清除瀏覽器的網站資料）就會一起刪除。

網路連線

  • App 完全不連網路：程式、曆法函式庫、字型都放在 App 裡。
  • 網頁版放在 GitHub Pages，字型向 Google Fonts 載入。打開網頁時，你的瀏覽器會向 GitHub 與 Google 的伺服器要檔案， 它們會收到一般的連線資訊（例如 IP 位址、瀏覽器種類），依各自的隱私權政策處理；我們拿不到這些資訊。

第三方

沒有廣告，沒有分析、追蹤或當機回報的工具，不和任何人分享資料，也不用你的資料做任何用途。

兒童

本工具不是針對兒童設計的，也不收集任何人（包括兒童）的資料。

政策的變更

這份政策若有變更，會更新本頁與上面的生效日期。

聯絡我們

有任何問題，請到 GitHub 的問題回報頁留言，或看支援頁。

Privacy Policy (English summary)

We do not collect any data. Charts are computed on your device; birth data you choose to save stays on that device only (the iOS app also keeps a backup copy in its own settings storage so it can restore saved charts if iOS clears web data). Nothing is uploaded, synced or shared. The iOS app makes no network connections at all. The web version is hosted on GitHub Pages and loads fonts from Google Fonts, which receive standard connection information (such as your IP address) under their own policies. There are no ads, analytics, tracking or crash-reporting tools. Questions: GitHub issues.
